# Assets

This folder holds architecture images for the project.

The **authoritative** system architecture diagram is the Mermaid source at
[`../diagrams/system_architecture.mmd`](../diagrams/system_architecture.mmd).

To export a PNG for embedding, paste the `.mmd` source into the
[Mermaid Live Editor](https://mermaid.live) and export the image into this
folder as `system_architecture.png`.
